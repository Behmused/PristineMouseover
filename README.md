# PristineMouseover

Adds a clear indicator to item tooltips in Ostranauts to show when an item is **Pristine**.

---

## Features

* Adds `(P)` to item mouseover tooltip if item is Pristine
* Adds `Pristine` label in the mega tooltip
* Works automatically when hovering over items

---

## Requirements

* Ostranauts — Build 0.15.0.26 (64) public_test
* BepInEx

---

## Installation

1. Install BepInEx into your Ostranauts directory
2. Place `PristineMouseover.dll` into:

   ```
   Ostranauts/BepInEx/plugins/
   ```
3. Launch the game

---

## Files

* `PristineMouseover.dll` → compiled plugin
* `.cs` files → source code

---

## Compatibility

* Should work with most mods
* May conflict with other tooltip/UI mods
